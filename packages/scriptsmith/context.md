# 全局上下文（微观模式用）

> 修改任何序列时，必须先读取本文件对应段落，确保不破坏全局连贯性。

## 全剧主题

生命的价值不在于活多久，而在于你愿意为谁而活。反抗命运的意义不是赢，而是反抗本身。

## 核心规则

1. 千秋万世书：张陵每次死亡后重生，可继承一项随机能力
2. 死神名单：按GB180乘客名单顺序追杀，通过编排"意外"执行
3. 死亡=数据：每次死亡修复书灵程序的一个bug
4. 乌鸦：死神的视觉化象征，在事故前/现场出现
5. 代码错误：人为干扰导致"意外"失败时，出现ERROR代码流

## 张陵能力时间线

| 获得时机 | 能力 | 等级 |
|---------|------|------|
| 第1次死亡（第1集） | 过目不忘 | F级 |
| 第2次死亡（第2集） | 驾驭达人 | E级 |
| 第3次死亡（第6集） | 危险预知 | - |
| 触发新循环（第23集） | 完美人类 | - |
| 重生（第36集） | 护身符（道具） | - |

## 序列间衔接要求

### phase1 → phase2a
- 第6集结尾：三人被爆炸碎片杀死，获得【危险预知】
- 第7集开头：第四次重开，张陵携带前三世记忆和三项能力重新出现在候机厅
- 关键变化：从"个人逃生"升级为"组队登机"

### phase2a → phase2b
- 第14集结尾：张陵在驾驶舱与机长对峙中
- 第15集开头：继续驾驶舱内的紧张对峙
- 关键变化：从"发现真相"到"亲自驾驶飞机"

### phase2b → phase3
- 第22集结尾：校园线展开，孙士颜的嫉妒与敌意
- 第23集开头：触发新循环获得【完美人类】
- 关键变化：从"航班线"彻底转入"地面追杀线"

### phase3 → phase4
- 第33集结尾：姚雅报警，张陵被捕
- 第34集开头：审讯室内，张陵面对警方
- 关键变化：从"主动救人"到"身陷囹圄"

### phase4 → phase5
- 第35集结尾：张陵在监狱遭遇死亡威胁
- 第36集开头：重生获得【护身符】，决定转变策略
- 关键变化：从"被动防御"到"主动对抗+公开真相"

### phase5 → phase6
- 第45集结尾：死神进化，计算能力增强
- 第46集开头：直升机被标记，终极清算开始
- 关键变化：从"团队胜利"到"全员灭杀+最终决战"
