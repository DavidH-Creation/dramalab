# 《死神：这届幸存者太难带了》全剧大纲

## 核心设定

张陵在GB180航班空难中死亡，意外激活《千秋万世书》获得重生能力。每次死亡可继承随机能力。一股被称为"祂"的死神力量按乘客名单顺序，通过因果链制造"意外"追杀所有幸存者。

**核心冲突**：张陵 vs 死神（书灵程序），每次死亡都是修复程序bug的数据。
**金手指**：千秋万世书（重生+继承能力）
**视觉符号**：乌鸦（死神实体化形象）

## 角色体系

| 角色 | 身份 | 核心标签 |
|------|------|---------|
| 张陵 | 18岁准大学生 | 冷静理性，领导力，"吾以吾名，换众生之锚" |
| 赵乾明 | 32岁公司经理 | 预知梦能力，胆小但忠心，最怕死却最不愿放弃人 |
| 林雅雅 | 准大学生 | 冷静细心，数据分析，张陵的核心搭档 |
| 池清澜 | 32岁乘务长 | 单亲妈妈，成熟稳重 |
| 王占军 | 军人 | 话少事多，行动派 |
| 书灵/死神 | 程序 | 乌鸦形象，编排连环意外 |

## 六阶段结构

### 第一阶段：新手村（第1-6集）★ 第6集为第一付费卡点

**核心任务**：建立设定，展示重生机制，制造前期爽点
**关键事件**：
- 第1集：GB180航班爆炸，张陵第一次死亡，获得【过目不忘】
- 第2集：逃离机场被坠机砸死（Flag连环），获得【驾驭达人】
- 第3-5集：联合赵乾明（预知梦）和林雅雅，尝试延迟飞机起飞
- 第6集（付费卡点）：成功延迟起飞，但发现"死神杀的是名单不是飞机"，爆炸碎片杀死三人，获得【危险预知】

**节奏**：3次死亡×3次重生，每集都有死亡/重生循环

### 第二阶段：开飞机的张陵（第7-22集）

**核心任务**：升级对抗规模，从"逃跑"到"正面对抗"
**关键事件**：
- 第7-8集：第四次重开，登机联合多人，排除人为破坏嫌疑
- 第9-11集：揭露乘务组罢工阴谋，化解第一重危机
- 第12-17集：发现真正威胁是机长王为富（自杀式坠机），驾驶舱对峙
- 第18集：张陵亲自驾驶飞机迫降成功，成为"英雄"
- 第19-22集：入学东吴大学，室友孙士颜嫉妒刺杀，校园线展开

**转折**：从空难生存→校园危机，场景大切换

### 第三阶段：死神怒了（第23-33集）

**核心任务**：死亡名单启动，幸存者逐个被追杀
**关键事件**：
- 第23-24集：触发新循环获得【完美人类】，躲过室友刺杀
- 第25-26集：王为富看守所割腕，李振酒店火灾死亡（名单启动）
- 第27-28集：警告空乘周雯、姚雅，不被相信
- 第29-32集：恐龙园追杀，"假死实验"救姚雅
- 第33集：西餐厅夺命餐车，姚雅报警导致张陵被捕

**情绪曲线**：救人→失败→再救→被误解被捕，虐感强烈

### 第四阶段：铁窗泪（第34-35集）

**核心任务**：低谷期，外部帮助线展开
**关键事件**：
- 张陵和赵乾明入狱，死神追杀不因牢狱而停
- 姚雅医院"意外"摔死，郑博健身房被砸
- 赵乾明在囚室死亡
- 林雅雅在外收集资料为张陵争取机会
- 张陵监狱内遭遇死亡威胁

**功能**：最黑暗时刻，为第五阶段的反击蓄力

### 第五阶段：组团刷副本（第36-45集）

**核心任务**：从被动防御转向主动对抗
**关键事件**：
- 第36集：重生获得【护身符】道具
- 第37集：直播李振死亡过程，公开死神规律
- 第38-39集：三名警察亲眼见证死亡，加入"鸦群"
- 第40-41集：总结死神五大规律，团队分工协作
- 第42-44集：连环追杀（车祸、马蜂、毒水），成功存活
- 第45集：死神进化，计算能力增强

**爽点密度**：最高，团队作战+规律破解+连续胜利

### 第六阶段：终极对决（第46-48集）

**核心任务**：揭示真相，终极牺牲
**关键事件**：
- 第46集：直升机被乌鸦标记，精准砸向安全屋，全员灭杀
- 第47集：张陵进入千秋万世书内部，书灵现身揭示真相——所有死亡都是修复程序bug
- 第48集：张陵用记录同伴"反抗瞬间"的本子冲击书灵，以"吾以吾名，换众生之锚"改写规则

**结局**：灰烬里，会开出新的花。
