# DramaLab

DramaLab is a monorepo for AI-assisted creative writing tools.

## Packages

- `packages/scriptsmith`: iterative screenplay optimizer and CLI
- `packages/studio`: DramaLab Studio backend and Next.js frontend

## Quick Start

```bash
python -m pytest -q
```

```bash
cd packages/studio/frontend
npm install
npm run build
```

## Naming

- `DramaLab`: the product and monorepo
- `ScriptSmith`: the screenplay optimization engine
- `DramaLab Studio`: the web UI
